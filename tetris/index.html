Como a IA funciona:
  1. A IA simula todas as posições/rotações possíveis para a peça atual.
  2. Para cada simulação, calcula as Features de Entrada (altura, buracos, etc.) do tabuleiro resultante.
  3. A Rede Neural (NN) processa essas features e gera um Score de Saída (quão "bom" é o resultado).
  4. A IA escolhe a simulação (posição/rotação) que gerou o maior Score.
  5. Executa os comandos (rotar, mover, descer) para alcançar essa posição escolhida.
A visualização mostra as features e o score da posição final escolhida pela IA.
